# PaintMix

Интерактивный веб-отчёт, объединяющий лабораторную работу № 2 «Моделирование процесса приготовления лакокрасочных материалов» и СРС 3 «Моделирование процесса приготовления лакокрасочных материалов с использованием интеллектуального управления».

## Запуск

Требуются Node.js 20 или новее и Python 3.10 или новее. Используются только стандартная библиотека Python и зависимости Node.js из `package.json`.

```bash
npm install
npm run dev
```

Откройте адрес Vite, который появится в терминале (по умолчанию `http://127.0.0.1:5173`). Для разработки запускаются два локальных процесса: React/Vite и Node.js API. Node.js запускает локальную Python-модель при поступлении запроса; третий постоянно работающий сервис не нужен. API доступно по адресу `http://127.0.0.1:3000`.

На Windows приложение по умолчанию запускает Python командой `py -3`; macOS/Linux — `python3`. Если Python доступен только по другому пути или имени, задайте переменную `PYTHON` перед запуском Node.js, например в PowerShell:

```powershell
$env:PYTHON = "C:\путь\к\python.exe"
npm run dev
```

Для production-сборки:

```bash
npm run build
npm start
```

После сборки приложение и API обслуживаются Node.js на `http://127.0.0.1:3000`.

JavaScript-тесты расчёта смешивания: `npm test`.

Python-тесты прогнозной модели:

```powershell
npm run test:python
```

## Структура приложения

- **Обзор:** назначение работы и схема смесительной установки с компонентами на входе и готовой смесью на выходе.
- **Теория:** описание процесса, его входов и результата.
- **Математическая модель:** дифференциальная модель смешивания, расчёт однородности и условных энергозатрат.
- **Моделирование:** объём, скорость, продолжительность, коэффициент интенсивности и требуемая однородность; диапазоны скорости и времени соответствуют заданию.
- **Оптимизация:** перебор допустимых режимов и поиск минимальных энергозатрат при достижении цели.
- **Результаты:** интерактивные графики, пять расчётных экспериментов, добавление текущего режима в сравнение и выводы.
- **Структурная схема:** семь этапов производства, входы, датчики, управляющие воздействия и выходы процесса.
- **Прогнозирование:** воспроизводимый синтетический набор из 400 строк, линейная регрессия, разделение на 320 обучающих и 80 тестовых наблюдений, прогноз при заданных параметрах, метрики R²/MAE/RMSE/MAPE, таблица фактических и прогнозных значений.
- **Интеллектуальное управление:** перебор 4 420 допустимых сочетаний температуры, скорости и времени; сравнение с традиционными фиксированными уставками и применение найденных уставок в интерактивной модели.
- **Контрольные вопросы:** два раздельных блока с ответами на все 10 вопросов СРС № 2 и все 10 вопросов СРС № 3; нумерация в каждой работе начинается заново.

## Модель расчёта

В методических указаниях баланс вещества записан как дифференциальное уравнение первого порядка:

```text
T · dC/dt + C = Pᵢ
C(t) = Pᵢ + (C₀ − Pᵢ) · e^(−t/T)
```

Здесь `C(t)` — концентрация во времени, `Pᵢ` — равновесная концентрация входящих компонентов, `C₀` — начальная концентрация, `T = V/G` — постоянная времени, определяемая объёмом `V` и суммарным расходом `G`.

В доступном тексте PDF формулы задания на однородность и энергозатраты не отображаются. Для интерактивного исследования используется явно заданная нормированная модель первого порядка:

```text
τ = 4 · √(V / 100) · (300 / ω) / k
H = 100 · (1 − e^(−t/τ))
E = V · (ω / 500)³ · t
```

`ω` — скорость мешалки в об/мин, `t` — время в минутах, `k` — коэффициент интенсивности, `H` — однородность в процентах. Для энергозатрат принято приближение, что мощность мешалки пропорциональна кубу скорости; `E` приведена к условным единицам и не является измеренной электрической энергией.

Оптимизатор перебирает скорости с шагом 5 об/мин и время с шагом 0,1 мин в заданных пределах. Среди режимов, для которых `H ≥ Hцель`, выбирается режим с минимальным `E`. Если допустимого режима нет, интерфейс сообщает об этом, а не показывает недостижимый результат как успешный.

Поскольку формулы в предоставленном PDF местами не распознаются, коэффициенты модели являются учебными, а не откалиброванными характеристиками конкретного смесителя. Для промышленного применения потребуются экспериментальные данные, калибровка и проверка модели.

## Модель прогнозирования и управление

Модуль `python/predictor.py` генерирует 400 учебных наблюдений с фиксированным начальным значением генератора случайных чисел. Синтетическая зависимость включает температуру, скорость мешалки, продолжительность, долю смолы, небольшое взаимодействие факторов и шум ±80 мПа·с. Набор не содержит производственных измерений и не демонстрирует качество на настоящей продукции.

Линейная регрессия реализована без сторонних библиотек: признаки стандартизуются по обучающей выборке, коэффициенты вычисляются методом наименьших квадратов с решением системы линейных уравнений. 320 наблюдений используются при обучении, 80 — для независимого тестирования. MAE и RMSE приводятся в мПа·с, MAPE — в процентах, R² — как доля объяснённой вариации.

Интеллектуальный контроллер использует прогноз вязкости и перебирает значения температуры 20–80 °C, скорости 100–500 об/мин и времени 1–20 минут. При поиске учитываются допуск ±4% от целевой вязкости (не менее 150 мПа·с), условие достижения целевой однородности и условные энергозатраты. В реальной установке такие рекомендации нельзя подавать непосредственно на исполнительные механизмы без калибровки, защитных ограничений и проверки оператором.

Тепловой баланс и формула нормированной однородности являются учебными моделями. Энергозатраты выражаются в условных единицах, а точность прогноза по синтетической выборке не является свидетельством промышленной эффективности.

## Структура проекта

- `src/App.jsx` — интерфейс, визуализация экспериментов, прогноз и управление.
- `src/styles.css` — адаптивные стили.
- `server/index.js` — API Node.js и локальный запуск Python-модуля.
- `server/model.js` — расчёты и оптимизация смешивания на JavaScript.
- `python/predictor.py` — генерация учебных данных, линейная регрессия, оценка и рекомендации контроллера.
- `python/test_predictor.py` — тесты Python-модели.

- Интерфейс: HTML5, CSS3, JavaScript, React.
- Сервер и API: Node.js, Express.
- Графики: Chart.js через `react-chartjs-2`.
- Расчётная модель и оптимизация: JavaScript, серверный модуль `server/model.js`.
- Прогнозирование и интеллектуальное управление: Python 3, без дополнительных Python-зависимостей.
