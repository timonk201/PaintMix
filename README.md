# PaintMix

Интерактивное веб-приложение для лабораторной работы № 2 «Моделирование процесса приготовления лакокрасочных материалов».

## Запуск

Требуется Node.js 20 или новее.

```bash
npm install
npm run dev
```

Откройте адрес Vite, который появится в терминале (по умолчанию `http://127.0.0.1:5173`). Для разработки запускаются два локальных процесса: React/Vite и Node.js API. API доступно по адресу `http://127.0.0.1:3000`.

Для production-сборки:

```bash
npm run build
npm start
```

После сборки приложение и API обслуживаются Node.js на `http://127.0.0.1:3000`.

Проверка расчётной модели: `npm test`.

## Структура приложения

- **Обзор:** назначение работы и схема смесительной установки с компонентами на входе и готовой смесью на выходе.
- **Теория:** описание процесса, его входов и результата.
- **Математическая модель:** дифференциальная модель смешивания, расчёт однородности и условных энергозатрат.
- **Моделирование:** объём, скорость, продолжительность, коэффициент интенсивности и требуемая однородность; диапазоны скорости и времени соответствуют заданию.
- **Оптимизация:** перебор допустимых режимов и поиск минимальных энергозатрат при достижении цели.
- **Результаты:** интерактивные графики, пять расчётных экспериментов, добавление текущего режима в сравнение и выводы.

## Модель расчёта

В методических указаниях баланс вещества записан как дифференциальное уравнение первого порядка:

```text
T · dC/dt + C = Pᵢ
C(t) = Pᵢ + (C₀ − Pᵢ) · e^(−t/T)
```

Здесь `C(t)` — концентрация во времени, `Pᵢ` — равновесная концентрация входящих компонентов, `C₀` — начальная концентрация, `T = V/G` — постоянная времени, определяемая объёмом `V` и суммарным расходом `G`.

В доступном тексте PDF формулы задания на однородность и энергозатраты не отображаются. Для интерактивного исследования используется явно заданная нормированная модель первого порядка:

```text
τ = 4 · √(V / 100) · (300 / ω) / k
H = 100 · (1 − e^(−t/τ))
E = V · (ω / 500)³ · t
```

`ω` — скорость мешалки в об/мин, `t` — время в минутах, `k` — коэффициент интенсивности, `H` — однородность в процентах. Для энергозатрат принято приближение, что мощность мешалки пропорциональна кубу скорости; `E` приведена к условным единицам и не является измеренной электрической энергией.

Оптимизатор перебирает скорости с шагом 5 об/мин и время с шагом 0,1 мин в заданных пределах. Среди режимов, для которых `H ≥ Hцель`, выбирается режим с минимальным `E`. Если допустимого режима нет, интерфейс сообщает об этом, а не показывает недостижимый результат как успешный.

Поскольку формулы в предоставленном PDF местами не распознаются, коэффициенты модели являются учебными, а не откалиброванными характеристиками конкретного смесителя. Для промышленного применения потребуются экспериментальные данные, калибровка и проверка модели.

## Стек

- Интерфейс: HTML5, CSS3, JavaScript, React.
- Сервер и API: Node.js, Express.
- Графики: Chart.js через `react-chartjs-2`.
- Расчётная модель и оптимизация: JavaScript, серверный модуль `server/model.js`.
